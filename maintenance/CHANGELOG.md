# Changelog

All notable changes to the Premium UI/UX Agent System are recorded here.

## 1.0.0 — Initial release
- Established the two-layer architecture: operational skill and authoritative design standard.
- Added governance, evaluation, technical guidance, workflows, and maintenance documents.
- Defined adaptive-but-demanding enforcement and agent autonomy boundaries.
- Added weighted 100-point evaluation and critical-failure acceptance gates.
- Established visual inspection, responsive, accessibility, motion, and truthful-reporting requirements.
- Added global Linux installation guidance while acknowledging agent-specific discovery mechanisms.
